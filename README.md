# Yutong YI

This is a static personal academic homepage for GitHub Pages.

## Fill content

Edit `content.js` first. Most visible text, links, publications, talks, and awards are controlled there.

To add a profile photo, put the image in `assets/`, then update:

```js
photo: {
  src: "profile-yutong-yi.jpg",
  alt: "Your name"
}
```

## Preview

Open `index.html` in a browser, or run a small local server from this folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
